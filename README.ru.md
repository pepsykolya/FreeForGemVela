# FreeForGemVela (ffgv) 0.4.0

Собственный GPU-майнер для **VELA** (Proof-of-Inference, целочисленный sd-turbo) на NVIDIA RTX 30 / 40 / 50.
Пакеты для HiveOS и Windows. Комиссия разработчика **1%**. English — [README.md](README.md).

- Каждая шара считается побитно так же, как консенсус-код ноды VELA, и перед отправкой перепроверяется.
- Встроенный автоандервольт с проверкой консенсус-канарейками. На VELA карта с перебором андервольта сначала считает
  *неверный* результат без всякого падения, поэтому майнер проверяет каждую настройку побайтно на известных результатах.
- Готовые режимы `speed`, `balance`, `eco`; сторож зависаний; резервные пулы; stratum по TLS; JSON API.

## Требования

- NVIDIA RTX 30 (sm_86), RTX 40 (sm_89) или RTX 50 (sm_120); видеопамять от 6 ГБ (лучше 8 ГБ).
- Драйвер NVIDIA с поддержкой CUDA 12 (R525 и новее; для RTX 50 — R570 и новее). Проверено на 580.178 (Linux) и 576.57 (Windows).
  Офсет памяти (`--moffset`, андервольт памяти) — драйвер R555 и новее.
- Linux x86_64 (HiveOS или любой дистрибутив на glibc) или Windows 10/11 x64.
- Управление частотами и андервольт требуют root (HiveOS запускает майнеры от root) или «Запуск от имени администратора» в Windows.
- Модель `sd-turbo-int.poisd` (1.19 ГБ, 1 187 585 285 байт). Скрипты запуска сами скачивают её один раз и проверяют:
  - https://huggingface.co/valereseach/vela-sd-turbo-int-v2/resolve/main/sd-turbo-int.poisd (официальный источник)
  - https://dl.ariabrain.com/vela-dl/sd-turbo-int.poisd (зеркало)
  - sha256 `ba38ab96b3398e22ea631d8a457350f91833e57463199d063663308513651f36`

## HiveOS

Полётный лист: монета **VELA** (если её нет в списке — добавьте свою), кошелёк, пул **Configure in miner**,
майнер **Custom** → Setup Miner Config:

| поле | значение |
|---|---|
| Miner name | `ffgv-hive` (подставится из URL) |
| Installation URL | `https://github.com/pepsykolya/FreeForGemVela/releases/download/v0.4.0/ffgv-hive-0.4.0.tar.gz` |
| Hash algorithm | `vela` |
| Wallet and worker template | `%WAL%.%WORKER_NAME%` |
| Pool URL | см. примеры пулов ниже (несколько через пробел — резервные) |
| Pass | `x` (или пусто) |
| Extra config arguments | например `--mode balance` |

При первом запуске `h-run.sh` скачивает модель в `/hive/miners/custom/vela-model` (одна копия на риг) и сверяет sha256.
Профили андервольта и записи о сбоях лежат в `/hive-config/ffgv` и переживают обновление майнера.
Пока майнер работает, его настройки частот главнее OC-профиля HiveOS; при остановке исходные значения возвращаются.
Панель HiveOS берёт скорость, температуры, вентиляторы и принятые/отклонённые шары из API майнера (`h-stats.sh`, порт 4078).

## Windows

1. Распакуйте `ffgv-0.4.0-windows-x64.zip` в папку без пробелов, например `C:\FreeForGemVela`.
2. Правой кнопкой по `start.bat` → «Изменить»: впишите в `WALLET` **свой** адрес (в примере стоит адрес разработчика),
   `POOL`, `WORKER`, при желании `MODE=balance`.
3. Запустите `start.bat` (от администратора, если используете `MODE`, `AUTO_UV` или частоты). При первом запуске скачается
   модель (1.19 ГБ, с проверкой sha256). Окно — это лог; Ctrl+C останавливает майнер и возвращает настройки карты.

Все поля описаны в `README-WINDOWS.txt` внутри пакета.

## Пулы

```
# AriaPool
ffgv --pool http://159.69.194.46:3349 --user vela1ВАШАДРЕС.rig1
# suprnova, stratum по TCP / по TLS (шифрование)
ffgv --pool stratum+tcp://vela.suprnova.cc:7601 --user vela1ВАШАДРЕС.rig1
ffgv --pool stratum+ssl://vela.suprnova.cc:7604 --user vela1ВАШАДРЕС.rig1
# соло через свою синхронизированную ноду VELA (RPC)
ffgv --pool http://RPCUSER:RPCPASS@127.0.0.1:19732 --user vela1ВАШАДРЕС
# резерв: первый пул основной, следующие — запасные
ffgv --pool stratum+ssl://vela.suprnova.cc:7604 --pool http://159.69.194.46:3349 --user vela1ВАШАДРЕС.rig1 --mode balance
```

Pool URL для HiveOS: `http://159.69.194.46:3349`, `stratum+tcp://vela.suprnova.cc:7601`, `stratum+ssl://vela.suprnova.cc:7604`,
`http://RPCUSER:RPCPASS@IP_НОДЫ:19732`. Для suprnova есть `--suggest-diff D` (стартовая сложность шары).

## Режимы и автоандервольт

| режим | RTX 30 | RTX 40 |
|---|---|---|
| `speed` | без лока ядра, память до +750 | без лока ядра |
| `balance` | лок ядра 1500, память до +1000 | лок ядра 2250 |
| `eco` | лок ядра 1400, память залочена на 5001 | лок ядра 2100, память залочена на 5001 |

Любой режим включает автоандервольт. Для RTX 50 и прочих карт пресета нет: частоты остаются как есть, подбирается
только андервольт. Ваши `--lock-cclock`, `--lock-mclock`, `--moffset`, `--pl`, `--uv-offset` главнее пресета.

`--auto-uv` без режима подбирает офсет ядра при заданных вами частотах. Как это работает: офсет ядра растёт шагами,
на каждом шаге раз в 5 с идут консенсус-канарейки (известные инференции, сверка побайтно), майнинг при этом не
останавливается. Первая проваленная канарейка или зависание — край; майнер берёт запас ниже края, подтверждает 150 с,
затем так же подбирает память (в режимах). Результат сохраняется по карте и по настройке частот (`uv.json`), следующий
запуск перепроверяет его примерно за 30 с. В майнинге канарейка идёт раз в 120 с; провал снижает офсет на 30 МГц.
Карта, зависшая на 40 с, ловится: майнер снижает то, что пробовал, возвращает ваши настройки и выходит с кодом 3, чтобы
HiveOS / `start.bat` его перезапустили. `--uv-reset` забывает профиль текущих частот, `--uv-reset-all` — все.

## Прочие параметры

```
--devices 0,1          какие карты (порядок nvidia-smi / PCI)      --batch N, --lanes N   (0 = авто)
--lock-cclock МГц      --lock-mclock МГц   --moffset МГц   --pl Вт   (одно значение или список по картам, '-' = не трогать)
--uv-offset МГц        фиксированный офсет ядра (с той же проверкой)   --uv-min / --uv-max МГц
--selftest             проверка движка: тест-вектор + 56 канареек  --bench 400   офлайн-замер скорости
--api-port ПОРТ        JSON-статистика на 127.0.0.1 (--api-bind АДРЕС)   --no-color   --version   --help
```

## API

`--api-port 4078` → `http://127.0.0.1:4078/` отдаёт JSON:
`version`, `engine`, `uptime`, `mode`, `pool`, `difficulty`, `total_inf_s`, `accepted`, `rejected`, `stale` и `gpus[]` с полями
`gpu`, `bus`, `name`, `inf_s`, `attempts`, `found`, `accepted`, `rejected`, `integrity_errors`, `canary_errors`, `alive`, `error`,
`power_w`, `temp_c`, `core_mhz`, `mem_mhz`, `core_offset`, `mem_offset`, `uv` (состояние автоандервольта).
Единицы в HiveOS: 1 «хеш» = 1 инференция.

## Комиссия разработчика

1% времени майнинга: один слот 60 с за каждые 100 минут, на адрес `vela1q8n67wrnsz0f5g4f6qwvmz6radx9jy6uujd64eh`.
В слоте майнер работает под логином комиссии на том же пуле (в соло блоки, найденные в слоте, платят на этот адрес),
затем возвращается к вашему логину. Каждый слот виден в логе.
